👕 Editor de Roupas Roblox

Editor online para criar camisas e calças do Roblox direto no navegador, usando o template oficial de 585×559 px. Desenhe, veja o resultado em um boneco (frente e costas) e baixe o PNG pronto para enviar ao Roblox.

Tudo em um único arquivo HTML, sem dependências, sem instalação e sem servidor.

✨ Recursos
🎨 Camisa e calça em camadas separadas, com o mesmo template do Roblox
🖌️ Ferramentas: pincel, borracha, preencher face inteira, conta-gotas e mover (pan)
📐 Guia do template com as faces coloridas (UP, FRONT, BACK, R, L, DOWN e braços/pernas) e linhas pontilhadas. Dá para ocultar
✂️ Recorte automático: só é possível pintar dentro das faces do template
👀 Preview em tempo real da frente e das costas, com a camisa por cima da calça
↩️ Desfazer (até 40 passos por camada) e limpar
🔍 Zoom automático (ajusta à tela) ou fixo em 100%, 150%, 200% e 300%
📱 Funciona no celular, com desenho por toque
⬇️ Download em PNG com fundo transparente (sem a guia), pronto para o Roblox
🚀 Como usar
Escolha 👕 Camisa ou 👖 Calça no topo.
Pinte as faces do template com as ferramentas. O que está fora das faces é cortado.
Confira o resultado no preview de frente e de costas.
Clique em ⬇️ Baixar PNG. O arquivo baixado é da camada ativa: roblox-camisa.png ou roblox-calca.png.
Envie o PNG no Roblox (Creator Dashboard → Development Items → Shirts / Pants).

Dica: a calça também pinta o torso. Para os dois arquivos, baixe uma vez em cada modo.

🗺️ Mapa do template
Região	Camisa	Calça
Parte central (cima)	Torso: UP, FRONT, BACK, R, L, DOWN	Torso (cintura/quadril)
Parte de baixo, esquerda	Braço direito	Perna direita
Parte de baixo, direita	Braço esquerdo	Perna esquerda

Cada face segue a lógica do Roblox: F = frente, B = costas, L = lado esquerdo, R = lado direito, U = topo e D = base.

💻 Rodar localmente

Não precisa instalar nada. Baixe o arquivo e abra no navegador:

bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
cd SEU-REPOSITORIO
# abra o arquivo no navegador
open roblox-clothes-editor.html      # macOS
xdg-open roblox-clothes-editor.html  # Linux
start roblox-clothes-editor.html     # Windows
🌐 Publicar no GitHub Pages
Renomeie o arquivo para index.html (ou mantenha o nome e acesse pelo caminho completo).
No repositório: Settings → Pages.
Em Source, escolha a branch main e a pasta / (root), depois salve.
Em alguns minutos o site estará em https://SEU-USUARIO.github.io/SEU-REPOSITORIO/.
